# AGENTS.md

Инструкции для ИИ-агентов (Claude Code, Codex, Hermes и др.) в этом репозитории.

## Проект

Локальный TTS-сервер на Qwen3-TTS VoiceDesign (MLX, macOS arm64) для Hermes Agent. Публичный репозиторий на GitHub.

| Путь | Что это |
| --- | --- |
| `scripts/hermes_tts_server.py` | FastAPI-сервер, держит модель, `GET /health`, `POST /tts` |
| `scripts/hermes_tts_client.py` | Командный провайдер Hermes, только stdlib |
| `scripts/healthcheck.sh` | Проверка `/health` |
| `install.sh`, `uninstall.sh` | Установка и снятие LaunchAgent, POSIX `sh` |
| `config/tts.yaml` | Фрагмент `~/.hermes/config.yaml` |
| `tests/` | Короткие тесты без модели |

## Запреты

- Не коммитить и не пушить. Не переписывать историю git. Это делает владелец.
- Не запускать `install.sh` и `uninstall.sh` и не трогать `launchctl`: они меняют систему пользователя.
- Не скачивать модель и не запускать сервер без явной просьбы.
- Не читать и не править `~/.hermes/config.yaml`.
- Не добавлять секреты, личные пути и имена в файлы репозитория.

## Команды

Для новых, ещё не добавленных в git файлов: `uv run --group dev pre-commit run --files <файлы>`.

Перед отчётом о готовности обе команды должны проходить.

## Правила кода

- Python 3.10+ (минимум рантайма, его проверяет `install.sh`), стиль и правила — ruff из `pyproject.toml`. Не ослаблять правила ради прохождения.
- Клиент — только stdlib: он запускается из Hermes на каждый запрос.
- Сервер никогда не скачивает модель: `HF_HUB_OFFLINE=1` в процессе, проверка `hf cache verify` в подпроцессе (пропускается, если рядом с сервером есть файл `SKIP_MODEL_VERIFY`), загрузка только из кэша. Не возвращать автозагрузку.
- Сервер зависит от `mlx-audio` версии, зафиксированной в `install.sh`. Перед правкой вызовов модели сверяться с исходниками этой версии, не по памяти.
- Shell-скрипты — POSIX `sh`, без bash-конструкций.
- Тесты короткие, без модели и сети: заглушки вместо сервера.
- Не раздувать функционал: новые возможности сначала в `TODO.md`.
